# 隐私与数据

同行处理位置、活动和设备状态等敏感信息。请仅在绑定双方知情且自愿的情况下使用。手机端会引导用户授权系统所需的权限，用户可以在系统设置中撤销。应用内可解除绑定或注销账号。

| 数据 | 用途 |
| --- | --- |
| 帐号、密码哈希与绑定关系 | 登录、注册与两人绑定 |
| 位置、精度与时间，以及可用的电池信息 | 地图、足迹、停留和位置提醒 |
| 经授权的屏幕、设备或应用时长状态 | 展示给已绑定的另一方 |
| 消息、报平安、SOS 与查看回执 | 双方互动 |
| 可选的 Firebase 设备令牌 | 向安装了相应构建的设备发出通知 |

服务会定期清理超过 30 天的位置样本和互动动态。解绑会清除本次绑定对应的轨迹和动态。管理员可通过独立账号查看服务器当前保留的位置、足迹、设备状态、应用时长、动态和地点。绑定后，应用按手机系统权限自动采集并向当前伴侣共享，可在「权限与共享」暂停。暂停共享后，服务器保留的数据仍可由管理员查看，直到被用户删除或按既有规则清理。管理员查看记录及禁用、恢复账号的操作会进入保留 30 天的审计日志。备份的保留和删除由部署者管理。

系统定位和本地网格可以独立于地图服务运行。使用默认 OpenStreetMap 街道底图时，地图服务会收到当前查看区域的瓦片请求和网络连接信息。无法加载街道底图时，应用保留本地网格、定位点和足迹，并提供重试。高德 SDK 在用户确认高德隐私说明后启用，适用高德的隐私政策，可在设置中停用。启用高德地点解析后，服务端会按授权将用于地点解析的坐标发送给高德。启用 Firebase 时会向 Firebase 发送通知所需的数据。扫一扫仅在配对时使用相机，二维码在设备上解析，服务器仅收到用于配对的邀请码。步数信号留在手机上，用于调节定位频率。

请勿在公共 Issue、截图、日志或数据库样本中提交真实的坐标、账号、地图 Key、推送凭据或服务器访问令牌。
